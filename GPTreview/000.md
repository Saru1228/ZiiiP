# Hutter Prize：PPMD + Transformer Residual / Affine 压缩实验笔记

> 目的：将当前关于 `fx2-cmix-transformer-v1`
> 的讨论整理为可直接在本地继续研究、实现和实验的技术上下文。
>
> 目标不是简单复现 Hutter Prize 结果，而是检验一个进一步的假设：
>
> **PPMD 已经提供了较强的 next-byte probability prior，Transformer
> 是否没有必要重新学习完整的 205-way distribution，而只需要学习一个低维
> residual / affine correction？**
>
> 如果成立，有机会进一步降低模型 description length，从而降低 Hutter
> Prize 的总压缩长度。

------------------------------------------------------------------------

## 1. 背景

关注项目：

-   Hutter Prize
-   `astOwOlfo/fx2-cmix-transformer-v1`
-   基于 `fx2-cmix` 的 Transformer 版本
-   数据集：`enwik9`
-   byte-level autoregressive compression
-   vocabulary size：205
-   `1 byte = 1 token`，无 tokenizer

核心思想是利用概率模型改善 arithmetic/range coding 的预测概率。

理想编码长度近似：

\[ L\_{`\text{data}`{=tex}} = -`\sum`{=tex}\_t `\log`{=tex}*2
p(x_t`\mid `{=tex}x*{\<t}) \]

但 Hutter Prize
不只计算压缩数据，也计算解压程序/模型自身的大小，因此真正关心：

\[ `\boxed{
L_{\text{total}}
=
L_{\text{model}}
+
L_{\text{compressed data}}
}`{=tex} \]

所以一个更小但 CE 略差的模型，可能反而得到更好的 Hutter score。

------------------------------------------------------------------------

## 2. 当前 fx2-cmix-transformer 的基本结构

当前获奖方案不是纯 Transformer。

粗略数据流：

``` text
enwik9
   │
   ▼
preprocessing
   │
   ├──────────────► traditional cmix predictors
   │
   ▼
PPMD
   │
   ▼
205-way probability distribution q_t
   │
   ▼
prior embedding
   │
   ▼
6M Transformer
   │
   ▼
205 logits / probabilities
   │
   ▼
ByteMixer / cmix mixers
   │
   ▼
bit probability
   │
   ▼
arithmetic coding
```

Transformer 直接接收 PPMD 的 probability distribution 作为输入信息。

当前 6M 配置大致为：

-   `vocabulary_size = 205`
-   `n_layers = 12`
-   `d_model = 192`
-   `d_mlp = 768`
-   3 attention heads
-   `d_head = 64`
-   Kimi Linear / normal attention 混合
-   pattern：

``` python
kimi_linear=[True, True, True, False] * 3
```

即约：

-   75% Kimi Linear
-   25% ordinary attention

普通 attention：

``` text
window_size = 1024
```

最终模型进行了激进量化：

-   weights：约 4 bit
-   activations：约 8 bit
-   权重采用 15-state representation（约 log2(15) bit/weight）
-   C++ AVX2 CPU inference

目的不仅是推理速度，更重要的是降低模型本身的 description length。

# 5. 关键发现：作者其实已经实现过 prior logit mixing

`pysrc/model.py` 中存在：

``` python
prior_logit_mixing
```

逻辑大致为：

\[ z_t = z_t\^{TF} + `\alpha`{=tex}\_t,
`\mathrm{center}`{=tex}(`\log `{=tex}q_t) \]

其中：

\[ `\alpha`{=tex}\_t =
`\operatorname{softplus}`{=tex}(w\^`\top `{=tex}h_t+c) \]

也就是说：

> Transformer 根据 hidden state 动态决定当前应该直接相信 PPMD prior
> 多大程度。

代码思想大致：

``` python
head_output = self.logit_mixing_head(last_activation)

prior_weight = softplus(
    head_output + softplus_inverse_of_one
)

prior_logprobs = priors.log()

clamped_prior_logprobs = prior_logprobs.clamp(
    min=self.cfg.prior_logprob_cap
)

clamped_prior_logprobs = make_mean_zero(
    clamped_prior_logprobs,
    dim=-1,
)

logits = logits + prior_weight * clamped_prior_logprobs
```

但关键点是：

``` python
prior_logit_mixing=False
```

最终 6M 获奖配置关闭了这一功能。

最终模型的 PPMD prior：

``` text
PPMD distribution
      ↓
prior embedding
      ↓
Transformer hidden state
```

而不是直接：

``` text
log PPMD
   +
Transformer logits
```

这给 residual / affine 路线留下了明确实验空间。

# 6. 我们提出的核心研究假设

当前 Transformer 学习：

\[ p_t = P(x_t`\mid `{=tex}x\_{\<t},q_t) \]

其中：

\[ q_t=P\_{`\text{PPMD}`{=tex}}(x_t`\mid `{=tex}x\_{\<t}) \]

但 PPMD 已经是一个很强的 predictor。

因此更自然的问题可能是：

> 不让 Transformer 从头预测 205-way distribution，而只预测 PPMD 的错误。

定义：

\[ q_t=P\_{`\rm PPMD`{=tex}} \]

Transformer distribution：

\[ p_t=P\_{`\rm TF`{=tex}} \]

log-space residual：

\[ `\boxed{
r_t
=
\log p_t-\log q_t
}`{=tex} \]

由于 softmax 对统一常数平移不敏感，应首先 center：

\[ r'\_t = r_t-`\frac{1}{V}`{=tex}`\sum`{=tex}*jr*{t,j} \]

其中：

\[ V=205. \]

真正的问题变成：

\[ `\boxed{
r'_t\text{ 是否位于一个低维子空间？}
}`{=tex} \]

------------------------------------------------------------------------

## 7.1 不能只看 explained variance

普通 PCA explained variance 可以作为诊断，但最终评价必须看：

\[ `\boxed{\text{cross entropy / bits per byte}}`{=tex} \]

因为 Hutter Prize 关心的是概率预测产生的编码长度。

对于 rank (k)：

\[ R_k=U_k`\Sigma`{=tex}\_kV_k\^`\top`{=tex} \]

构造：

\[ z_t\^{(k)} = `\log `{=tex}q_t+r_t\^{(k)} \]

然后：

\[ `\hat `{=tex}p_t\^{(k)} = `\operatorname{softmax}`{=tex}(z_t\^{(k)}).
\]

真实 target 为 (y_t)，计算：

\[ `\mathrm{bpb}`{=tex}\_k = -`\frac`{=tex}1N `\sum`{=tex}\_t
`\log`{=tex}\_2 `\hat `{=tex}p_t\^{(k)}(y_t). \]

比较：

``` text
PPMD-only
rank-1
rank-2
rank-4
rank-8
rank-16
rank-32
rank-64
full Transformer
```

# 9. Affine 实验族

建议不要直接做 full affine。

按照复杂度递增。

------------------------------------------------------------------------

## Experiment A：global temperature / scalar affine

\[ z_t = `\alpha`{=tex}`\log `{=tex}q_t+b \]

其中 (`\alpha`{=tex}) 是 scalar。

实际上统一 scalar bias 对 softmax 没有意义，因此核心就是：

\[ `\boxed{
p_t
=
\operatorname{softmax}
(\alpha\log q_t)
}`{=tex} \]

这测试：

> PPMD 是否主要存在 calibration / temperature error？

成本近似 1 parameter。

------------------------------------------------------------------------

## Experiment B：dynamic scalar affine

\[ z_t = `\alpha`{=tex}\_t`\log `{=tex}q_t \]

其中：

\[ `\alpha`{=tex}\_t=f(h_t). \]

这与仓库已有的：

``` text
prior_logit_mixing
```

非常接近。

新增参数约：

\[ 192+1. \]

值得直接重新启用并测试。

------------------------------------------------------------------------

## Experiment C：byte-specific bias

\[ z_t = `\alpha`{=tex}\_t`\log `{=tex}q_t+b \]

其中：

\[ b`\in`{=tex}`\mathbb `{=tex}R\^{205}. \]

这允许模型学习：

``` text
PPMD 系统性低估哪些 byte
PPMD 系统性高估哪些 byte
```

参数成本极低。

# 10. Low-rank residual

这是目前最值得深入的方向。

令：

\[ B`\in`{=tex}`\mathbb `{=tex}R\^{205`\times `{=tex}r} \]

Transformer / 小型 context model 只预测：

\[ c_t`\in`{=tex}`\mathbb `{=tex}R\^r. \]

最终：

\[ `\boxed{
z_t
=
\alpha_t\log q_t
+
Bc_t
+
b
}`{=tex} \]

然后：

\[ p_t=`\operatorname{softmax}`{=tex}(z_t). \]

解释：

### PPMD

负责：

> 下一个 byte 大概是什么？

### residual model

负责：

> PPMD 在当前 context 下会怎样系统性地错？

### low-rank basis

负责：

> 把这种 error 映射回 205-dimensional probability space。

# 11. 参数量

假设 hidden dimension：

\[ d=192 \]

rank：

\[ r=8 \]

需要：

\[ W_c`\in`{=tex}`\mathbb `{=tex}R\^{r`\times192`{=tex}} \]

以及：

\[ B`\in`{=tex}`\mathbb `{=tex}R\^{205`\times `{=tex}r}. \]

参数约：

\[ 192r+205r = 397r. \]

当：

\[ r=8 \]

时：

\[ 3176`\text{ parameters}`{=tex}. \]

FP32：

\[ 3176`\times4`{=tex} `\approx12.4`{=tex}`\text{ KB}`{=tex}. \]

量化以后只需要几 KB。

所以 low-rank residual head 本身几乎免费。

# 13. Hutter Prize 的 break-even 思维

评价不能只看：

``` text
validation loss
```

必须计算：

\[ L\_{`\text{total}`{=tex}} = L\_{`\text{model}`{=tex}} +
L\_{`\text{data}`{=tex}}. \]

假设模型缩小：

\[ `\Delta `{=tex}M \]

bytes。

允许的数据编码恶化约：

\[ `\Delta`{=tex}`\mathrm{bpb}`{=tex}\_{`\max`{=tex}} =
`\frac{8\Delta M}{N}`{=tex} \]

其中 enwik9：

\[ N`\approx10`{=tex}\^9. \]

例如省：

\[ 1.43`\text{ MB}`{=tex} \]

则允许：

\[ `\Delta`{=tex}`\mathrm{bpb}`{=tex} `\approx`{=tex}
`\frac{1.43\times10^6\times8}{10^9}`{=tex} `\approx0.0114`{=tex}. \]

也就是说：

> 即使 smaller residual model 的 CE 比当前 Transformer
> 稍差，只要模型文件缩得足够多，总 Hutter score 仍可能更优。

# 15. Residual preprocessing

计算：

``` python
R = logp - logq
```

然后去掉 softmax 无意义的 common offset：

``` python
R -= R.mean(axis=1, keepdims=True)
```

这一步非常重要。

否则 PCA 会浪费维度解释：

``` text
logit translation
```

而这种 translation 对 probability distribution 完全没有影响。

------------------------------------------------------------------------

# 16. SVD 不建议直接 full SVD

如果：

``` text
N = 10,000,000
V = 205
```

矩阵已经非常大。

建议：

``` python
sklearn.utils.extmath.randomized_svd
```

或者 incremental covariance。

由于 (V=205) 很小，更高效的方法是计算：

\[ C=R\^`\top `{=tex}R/N \]

这是：

\[ 205`\times205`{=tex} \]

然后 eigendecomposition。

伪代码：

``` python
C = np.zeros((V, V), dtype=np.float64)

for chunk in residual_chunks:
    C += chunk.T @ chunk

C /= N

eigvals, eigvecs = np.linalg.eigh(C)
```

按 descending order 排序即可。

这样无需把完整 residual matrix 放入 RAM。

# 17. 更重要：compression-aware rank evaluation

PCA 最小化：

\[ \|R-`\hat `{=tex}R\|\_2\^2 \]

但我们真正想最小化：

\[ -`\log `{=tex}p(y_t). \]

所以 PCA 只是第一步。

第二步应该固定 basis：

\[ B_r \]

然后寻找：

\[ c_t \]

使：

\[ p_t = `\operatorname{softmax}`{=tex} (`\log `{=tex}q_t+B_rc_t) \]

尽量逼近真实 target CE。

可以先使用 PCA projection：

\[ c_t=B_r\^`\top `{=tex}r_t \]

作为 upper-bound diagnostic。

然后再训练一个小模型预测 (c_t)。

------------------------------------------------------------------------

# 18. 一个非常重要的 distinction

Residual SVD 使用：

\[ p_t\^{TF} \]

因此它回答的是：

> "现有 Transformer 相对于 PPMD 的输出修正是否低秩？"

它并不能直接证明：

> "仅靠小模型就能根据 context 预测这些 residual coefficients。"

所以实验分两层：

### Layer 1：representation question

\[ r_t \]

是否 low-rank？

### Layer 2：prediction question

如果 low-rank：

\[ c_t \]

是否容易从 context 预测？

只有两者都成立，才能真正缩小 Transformer。

# 20. 一个更激进的 affine formulation

可以研究：

\[ z_t = A_t`\log `{=tex}q_t+b_t. \]

但 full：

\[ A_t`\in`{=tex}`\mathbb `{=tex}R\^{205`\times205`{=tex}} \]

过于昂贵。

更合理：

\[ A_t = I+U_tV_t\^`\top`{=tex}. \]

即：

\[ `\boxed{
z_t
=
\log q_t
+
U_tV_t^\top\log q_t
+
b_t
}`{=tex} \]

rank-1：

\[ z_t = `\log `{=tex}q_t + u_t(v_t\^`\top`{=tex}`\log `{=tex}q_t) +
b_t. \]

rank-(r)：

\[ z_t = `\log `{=tex}q_t + U_t(V_t\^`\top`{=tex}`\log `{=tex}q_t) +
b_t. \]

但这一方向应排在 simple residual basis 之后，因为动态矩阵的 inference 和
parameter cost 更复杂。

# 23. 另一个值得检查的问题：条件 residual rank

全局 residual 可能并不低秩，但条件 residual 可能低秩。

例如按 context 分类：

``` text
text
XML / markup
numbers
whitespace
UTF-8
capitalization
punctuation
```

可能分别存在不同 low-rank subspace。

于是：

\[ r_t `\approx`{=tex} B\_{c_t}a_t. \]

可以变成：

``` text
mixture of low-rank residual experts
```

例如：

\[ K=4 \]

个 basis bank：

\[ B_1,B_2,B_3,B_4. \]

一个很小的 gating model 选择/混合。

这可能比单一 global rank-16 更强，同时仍很便宜。

# 24. 为什么这个方向理论上有意义

这个问题可以理解为：

\[ `\text{prediction}`{=tex} =
`\text{structured statistical prior}`{=tex} +
`\text{learned correction}`{=tex}. \]

PPMD 已经编码：

``` text
local repetition
short context statistics
symbol continuation
```

Transformer 更擅长：

``` text
long-range dependency
semantic structure
document structure
context-dependent calibration
```

因此没有必要让两者重复承担相同的预测任务。

理想分工：

\[ `\boxed{
P_{\rm final}
=
P_{\rm structured\ prior}
\times
P_{\rm residual}
}`{=tex} \]

log-space：

\[ `\boxed{
\log P_{\rm final}
=
\log P_{\rm PPMD}
+
r_\theta
-
\log Z
}`{=tex} \]

这天然就是 residual learning。

# 25. 与 MDL 的关系

这条路线真正有意思的地方不只是工程压缩。

它对应：

\[ L(D,M) = L(M)+L(D`\mid `{=tex}M). \]

复杂 Transformer：

``` text
更低 residual entropy
但更高 model description length
```

小 residual model：

``` text
略高 residual entropy
但更低 model description length
```

最优点并不一定是最大模型。

因此可以研究：

\[ `\boxed{
\arg\min_M
[
L(M)+L(D\mid M)
]
}`{=tex} \]

Hutter Prize 本质上提供了一个非常直接的实验环境来研究这种 trade-off。

# 28. 当前核心判断

目前最重要的不是立刻设计更复杂的 affine layer。

真正应该先回答：

\[ `\boxed{
\text{Transformer 对 PPMD 的 correction 到底有多少 intrinsic dimension？}
}`{=tex} \]

如果答案是：

``` text
8
16
32
```

那么这会给模型压缩提供非常明确的结构依据。

特别是如果：

\[ r`\le16`{=tex} \]

已经保留绝大部分 compression gain，那么下一阶段真正有潜力的方向是：

\[ `\boxed{
\text{strong PPMD prior}
+
\text{small sequence model}
+
\text{low-rank residual head}
}`{=tex} \]

而不是：

``` text
PPMD
+
full 6M Transformer predicting 205 logits from scratch
```

最终目标：

\[ `\boxed{
\text{用更短的模型描述，换取几乎相同的数据描述长度}
}`{=tex} \]

从而真正降低：

\[ `\boxed{
L(M)+L(D\mid M)
}`{=tex} \]

这也是下一轮实验的核心。
