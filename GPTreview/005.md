# 005 按 004.md 执行后的结果：log-ratio PCA 有明显正向信号

日期：2026-10-08

## 先说结论

这一步有进展。

按照 `004.md` 的指导，我没有扩大到 10MB / 100MB，而是继续在 1MB 样本上测试：

```text
Log-ratio residual PCA
```

结果比之前的 raw PCA 明显好。

之前最好的 raw PCA：

```text
176,294 bytes
追回 44 bytes
追回比例约 3.6%
```

这次最好的 log-ratio PCA：

```text
176,064 bytes
追回 274 bytes
追回比例约 22.7%
```

这已经超过 `004.md` 里定义的 20% 门槛，可以算“明显正向”。

## 这次测试的意思

之前我们直接在概率上做 PCA，效果很弱。

这次换了坐标系，不直接看：

```text
Transformer 概率 - PPMD 概率
```

而是看：

```text
log(Transformer 概率) - log(PPMD 概率)
```

直觉上，它问的是：

```text
Transformer 相对于 PPMD，
到底把每个候选字符的概率乘大了多少、乘小了多少？
```

这个坐标系更符合概率分布本身的结构。

## 核心数字

基线：

| 方法 | 压缩后大小 |
|---|---:|
| 完整 Transformer | 175,130 bytes |
| PPMD 对照 | 176,338 bytes |

这说明 PPMD 到完整 Transformer 之间，有：

```text
1208 bytes
```

可以争取。

这次结果：

| 方法 | 压缩后大小 | 追回比例 |
|---|---:|---:|
| raw PCA rank64 | 176,294 | 3.6% |
| log-ratio rank32 alpha0.6 | 176,205 | 11.0% |
| log-ratio rank64 alpha0.6 | 176,078 | 21.5% |
| log-ratio rank64 alpha0.8 | 176,064 | 22.7% |

最好的组合是：

```text
rank = 64
alpha = 0.8
压缩后大小 = 176,064 bytes
```

## 怎么解读

这说明：

```text
坐标系确实很重要。
```

在普通 probability space 里，低秩结构很弱。

但在 log-ratio space 里，低秩结构明显更有用。

这支持 `004.md` 里的判断方向：

```text
当前 PCA 不是完全没用，
而是 raw probability 坐标系不太对。
```

## 但这还不是最终成功

完整 Transformer 仍然明显更好：

```text
完整 Transformer：175,130 bytes
当前最好低秩版本：176,064 bytes
差距：934 bytes
```

所以现在不能说我们已经替代了 Transformer。

只能说：

```text
Transformer 相对 PPMD 的修正，
确实有一部分可以被 log-ratio 低秩结构解释。
```

另外，这还是 oracle 实验。

也就是说，它用了完整 Transformer 概率文件来拟合 PCA。真正做 codec 时，还要解决：

```text
这些低维修正怎么由解码端也能知道？
```

这个问题现在还没解决。

## 下一步不应该做什么

现在仍然不建议直接跑 10MB 或 100MB。

原因是：

```text
我们已经发现一个正向结构，
但还不知道它是全局结构，
还是只在某些 context 里特别明显。
```

如果直接扩大数据，可能只是更贵地重复当前结论。

## 下一步应该做什么

按照 `004.md`，下一步应该做两个更有判别力的实验。

第一，分析 Transformer 到底在哪些位置赢：

```text
gain = log2(pTransformer[真实字符] / pPPMD[真实字符])
```

要看它的收益是：

```text
到处都有一点
```

还是：

```text
集中在少数困难位置
```

第二，做 entropy-conditioned local PCA：

```text
按 PPMD 的不确定性分桶
每个桶里单独做 PCA
```

重点比较：

```text
global rank32
vs
4 buckets × local rank8
```

如果 local PCA 明显更好，就说明 residual 更像：

```text
不同 context 下的局部低维结构
```

而不是一个全局低维平面。

## 当前判断

当前判断是：

```text
继续。
```

但继续的方向不是扩大数据，而是验证：

```text
Transformer 的收益是否集中在特定 context？
是否存在局部低维结构？
```

这一步结果已经足够支持进入 `004.md` 的下一阶段。
